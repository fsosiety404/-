**если хотите посмотреть как выглядит сайт который уже захостен переходи по этой ссылке** https://testsitesfirsts.pythonanywhere.com/
**инструкция по запуску: для начала в папке social_network создайте файл .env и далее через редактор или блокнот напишите информацию 
ключ шифрования email его можно сгенерировать через библиотеку cryptography и далле написать для начала в файле .env SHIF_KEY=ваш ключ
далее либо изменить settings.py if debug not: просто удалить либо захостить на сайте pythonanywhere либо проще просто в settings.py в переменной DEBUG=False исправить на DEBUG=True
далее для запуска сервера что бы посмотреть сайт в терминале pycharm или vs code выполнить python manage.py runserver**
